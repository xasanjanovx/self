# Подключение: умный дом и биллинг Google Cloud

Оба подключения необязательны: пока ключей нет, JES честно говорит, чего не хватает, и ничего не ломается.

## Умный дом (свет, ТВ, кондиционер голосом) — Tuya Cloud / Smart Life

**Что купить** (всё с пометкой «Tuya» / «Smart Life», Wi-Fi 2,4 ГГц; обычно недорого — порядка 5–15 $ за штуку):
1. **Свет:** Wi-Fi лампа E27 *или* Wi-Fi реле/выключатель в разрыв провода (если нужна именно люстра и выключатель на стене).
2. **ТВ и кондиционер:** один **ИК-пульт Wi-Fi (ИК-хаб)** на комнату — он «видит» ТВ и кондиционер и шлёт команды как обычный пульт.
3. По желанию: умная розетка (чайник, обогреватель).

**Один раз настроить:**
1. Приложение Smart Life → добавить устройства; в ИК-хабе добавить «виртуальные пульты» ТВ и кондиционера (по бренду).
2. https://iot.tuya.com → Cloud → Create Cloud Project (Industry: Smart Home, регион — как у аккаунта приложения; в приложении: Я → ⚙ → Аккаунт → Регион).
3. В проекте: **Devices → Link App Account** → отсканировать QR приложением Smart Life; там же виден **UID**.
4. **Service API** проекта: подписаться на *IoT Core* и *IR Control Hub Open Service* (бесплатные пробные подписки Tuya иногда просит продлевать).
5. Мне дать **Access ID** и **Access Secret** — внесу в `.env` сервера: `TUYA_ACCESS_ID`, `TUYA_ACCESS_SECRET`, `TUYA_UID`, `TUYA_ENDPOINT`
   (Центральная Европа — `https://openapi.tuyaeu.com`, Индия — `https://openapi.tuyain.com`, США (запад) — `https://openapi.tuyaus.com`).
6. Сказать JES: «найди устройства дома». Потом: «Джес, включи свет», «выключи кондиционер», «кондиционер на двадцать четыре», «включи тв».

Заметки: «включи/выключи ТВ» шлёт клавишу питания (у большинства ТВ она одна — переключатель), состояние ТВ не проверить; состояние
кондиционера бот помнит сам. Названия можно менять: «лампу назови свет в комнате», «кондиционер ещё зови кондей» (home_rename).

## Баланс и расход Google Cloud — автоматически (экспорт биллинга в BigQuery)

Без этого JES считает по своему счёту и по тому, что ты сам назвал («на Google Cloud осталось 270 долларов» — запомнит).
Точные цифры от Google:
1. Google Cloud Console → **Billing → Billing export → BigQuery export → Standard usage cost → Edit settings**: проект и набор данных (создать, например, `billing_export`). Данные появятся через несколько часов и начнутся с даты включения.
2. **IAM → Service Accounts → Create**: роли *BigQuery Data Viewer* и *BigQuery Job User*; **Keys → Add key → JSON** — скачать файл.
3. Файл ключа положить на сервер (например, `/opt/codex-bots/self/data/gcp_sa.json` → в контейнере `/app/data/gcp_sa.json`); в `.env`:
   `GCP_SA_FILE=/app/data/gcp_sa.json` и `GCP_BILLING_TABLE=проект.набор.gcp_billing_export_v1_XXXXXX` (имя таблицы видно в BigQuery после первой выгрузки).
4. Спросить JES: «какой баланс на Google Cloud?» — расход на API (Gemini/Vertex) и на другие сервисы он покажет отдельно.

Остальное — в `bot/gcp_billing.py` (докстринг) и `bot/smarthome.py`.
