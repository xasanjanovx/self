# Self — личный Telegram-ассистент

Один бот для себя: **питание** (КБЖУ по фото/тексту/голосу), **финансы**
(доходы/расходы/долги/переводы + статистика по категориям) и **вакансии**
(оформление поста для канала @ishdasiz + промпт для картинки).

Стек: Python 3.12 · aiogram 3 · Supabase (async) · Gemini · Docker.

## Как устроено

```
bot/
  main.py          сборка бота, middlewares, фоновые задачи
  config.py        настройки из env
  context.py       синглтоны: settings / db / ai
  db.py            async-доступ к Supabase (постраничное чтение, без блокировок)
  cache.py         in-memory TTL-кэш на пользователя (сбрасывается при записи)
  services.py      данные для панелей одним вызовом + инвалидация кэша
  ai.py            Gemini: JSON-режим, thinkingBudget=0 для разбора, короткий retry
  categories.py    фиксированный справочник категорий (ключи + ru/uz названия + алиасы)
  finance.py       чистая логика финансов: балансы, статистика, локальный парсер
  nutrition.py     план КБЖУ, агрегаты дневника
  vacancy.py       детект вакансии, нормализация, сборка поста, промпт
  handlers/        menu · nutrition · finance · assistant(задачи/заметки/цели) · vacancy · analytics ·
                   agent(«Джарвис») · inbox(fallback)
  tasks.py         локальный разбор задачи «что + когда» (завтра/в пятницу/3 ноября/18:00) + группировка
  agent_tools.py   инструменты агента (function calling): операции, долги, лимиты, регулярные,
                   напоминания, дневник еды, план КБЖУ, настройки, экраны, hand_off парсерам
  undo.py          единый откат последнего действия (в т.ч. многошагового хода агента)
  reminders.py     формат напоминаний (текст + ссылки по кругу, однократные)
  agent_tools_assistant.py  инструменты заметок/задач/целей/сроков долгов
  analysis.py      глубокий анализ (тренды, аномалии, прогноз, цели) — без AI
  proactive.py     правила проактивных подсказок (+ воркер в workers.py)
  voice.py         голосовые ответы: Gemini TTS → ffmpeg → OGG/Opus
  screen.py        «один живой экран»: панель редактируется на месте, мусор удаляется
```

## Главный экран

Кнопки: **Питание · Финансы · Задачи · Цели · Вакансии · Аналитика · Настройки · Обновить**.
Карточка «Цели и дела» на главном: просроченные и сегодняшние задачи + до 3 ближайших
(с датой, потом без даты), остальное — на экране «Задачи».

- **Задачи** — списки «Просрочено / Сегодня / Ближайшие / Без даты», ✅ по кнопке,
  «Выполненные» (🗑 удалить), «Заметки». Текст/голос на этом экране разбирается локально
  без AI (`tasks.py`): «позвонить маме завтра в 18:00», «в пятницу забрать посылку»,
  «3 ноября поздравить брата», «5 числа отдать долг», «через неделю сдать отчёт».
  Команды («удали…», «перенеси…»), вопросы и «запомни…» уходят Джарвису; «такси 25000» —
  в финансы.
- **Цели** — прогресс, срок, «нужно в месяц», успеваем ли при текущем темпе;
  «Отложить» + сумма (можно «-200к»), «Закрыть цель», «Удалить». Новая цель — текстом
  через Джарвиса («накопить 10 млн на ноутбук к январю»).

## «Джарвис»

Любой текст, который не поймали быстрые правила («такси 25000», «съел плов»,
вакансия), уходит агенту на Gemini с инструментами. Агент сам решает, что делать,
и **выполняет сразу** — без «точно?»; любой ход откатывается кнопкой «↩️ Отменить»
(30 минут). Помнит последние реплики (30 минут), поэтому работают уточнения.

Примеры:
- «удали вчерашнее такси», «удали все такси за неделю», «обед был не 40 а 45 тысяч»
- «убери без имени из долгов», «на карте сейчас 500к», «кто мне должен?»
- «лимит на еду 700 тыс», «убери все лимиты», «поставь интернет 150к 5-го числа на паузу»
- «напоминай по будням в 7:00 зарядка», «напомни через 2 часа позвонить маме»,
  «каждый вечер присылай по одному видео: <ссылки>»
- «удали пряник из дневника», «вчера ещё съел плов 600 ккал», «поставь норму 2200 ккал»
- «выключи вечернюю сводку», «отчёт раз в месяц», «переключи на узбекский»
- «сколько потратил на еду в этом месяце?», «что я ел вчера?», «что мне поесть вечером?»
- «покажи лимиты / статистику / регулярные / задачи / цели» — откроет экран
- «проанализируй мои данные», «где я переплачиваю?», «прогноз до конца месяца» —
  глубокий разбор (`analysis.py`: тренды по месяцам, изменения по категориям,
  прогноз остатка, лимиты под угрозой, аномалии и дубли, частые мелкие траты,
  скрытые подписки, питание); та же кнопка «🧠 Глубокий анализ» в Аналитике
- «запомни, что у брата день рождения 3 ноября», «купить лампочку», «позвонить маме
  завтра в 18:00», «мои дела на сегодня», «сделал» — заметки и задачи (задача со
  временем → напоминание в срок, с датой → в утренней сводке)
- «хочу накопить 10 млн на ноутбук к январю», «отложил 500к на ноутбук», «как дела с
  целью?» — цели накоплений: прогресс на главном экране, «нужно откладывать X/мес»,
  предупреждение, если при текущем темпе не успеваем
- «дал Асилбеку 1 млн, вернёт до 5 октября», «Асилбек вернёт до пятницы» — срок долга:
  видно на экране Финансов, бот напомнит за день и при просрочке (с готовым текстом
  сообщения должнику — кнопка «скопировать»)
- всё остальное (перевод, вопрос, совет) — ответит как обычный ассистент
- голосовой вопрос → ответ текстом **и голосом** (Gemini TTS + ffmpeg; выключается в Настройках)

### Проактивные подсказки (`proactive.py`)

Раз в 10 минут бот проверяет правила и пишет сам — только если есть повод, каждая
подсказка один раз (журнал `alerts_log`): срок долга завтра/сегодня/просрочен;
сегодняшние траты в 3+ раза выше обычных; регулярный платёж через ≤ 2 дня, а денег
не хватает; лимит категории при текущем темпе будет превышен; цель накопления не
успевается; питание сильно ниже/выше нормы несколько дней; воскресный итог недели
от Джарвиса. Выключается в Настройках («💡 Подсказки Джарвиса»).

Если под фразу подходит несколько записей — агент покажет нумерованный список и
спросит («вторую»). «Такси 25000» / «съел плов» / текст вакансии агент передаёт
обычным парсерам с их экраном подтверждения.

Настройки: `AGENT_MODEL` (по умолчанию = `GEMINI_MODEL`), `AGENT_THINKING_BUDGET`
(0 — быстрее; 512–1024 — чуть умнее в сложных цепочках).

Принципы скорости:
- ни одного блокирующего вызова в event loop (Supabase и Gemini — async);
- Джарвис: один ход агента = 1–3 вызова Gemini (~2–5 с), инструменты — параллельные
  вызовы в одном ответе модели;
- данные панели читаются параллельно (`asyncio.gather`) и кэшируются;
- простые операции («такси 25000», «обед 40к, зарплата 5 млн») разбираются
  локально без AI; AI подключается только для долгов/переводов и сложных фраз;
- `callback.answer()` вызывается сразу — «часики» на кнопке не висят;
- бот пускает только `ALLOWED_TELEGRAM_IDS` (личный).

## Запуск локально

```bash
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
copy .env.example .env   # заполнить
python -m bot.main
pytest -q
```

## Supabase

1. `sql/schema.sql` — базовые таблицы.
2. `sql/migrations/001_settings_tables.sql` — профиль питания, счета, настройки отчёта (обязательно).
3. `sql/migrations/002_screen_message_id.sql` — чтобы меню не дублировалось после рестарта.
4. `sql/migrations/003_finance_category_keys.sql` — приведение старых категорий к ключам (по желанию).
5. `sql/migrations/004_v2_features.sql` — утренние/вечерние сводки, лимиты, регулярные платежи (обязательно для этих функций).
6. `sql/migrations/005_assistant.sql` — заметки, задачи, цели, сроки долгов, проактивные подсказки, переключатели (обязательно для этих функций).

Ключ — `service_role`, поэтому бот должен жить только в защищённой среде и с
`ALLOWED_TELEGRAM_IDS`.

## Деплой на сервер (Docker)

Бот живёт в `/opt/codex-bots/self`, контейнер `codex-self-bot` из
`/opt/codex-bots/docker-compose.yml` (`env_file: ./self/.env`).

С локальной машины (пушит `main` и пересобирает контейнер по SSH):

```bash
bash scripts/deploy_remote.sh
```

Или прямо на сервере:

```bash
bash /opt/codex-bots/self/scripts/deploy.sh
```

Логи: `docker logs -f codex-self-bot`.

## Использование

- **Финансы**: `такси 25000` · `обед 40к наличными` · `зарплата 5 млн` ·
  `дал в долг 200000` · `снял с карты 300000` · несколько операций через запятую ·
  вопрос: «сколько я потратил на еду в этом месяце?»
- **Питание**: фото блюда, «омлет из 3 яиц и кофе», голосом.
- **Вакансии**: текст/пересланный пост/фото с подписью → пост на узбекской
  латинице по шаблону канала + отдельным сообщением промпт для картинки (16:9).
  `VACANCY_CHANNEL=@канал` включает публикацию в канал одной кнопкой (бот — админ).
- **Лимиты**: Финансы → Лимиты — месячный лимит на категорию; статистика и
  подтверждение операции предупреждают при 80% и при превышении.
- **Регулярные платежи**: Финансы → Регулярные — «интернет 150000 5»; в день
  платежа бот спрашивает «Оплатил?» (запись в одно нажатие), панель показывает
  «обязательные до конца месяца → свободно».
- **Быстрый ввод**: просто число (`25000`) → выбор категории кнопками; фото чека
  в разделе Финансы → сумма и категория с фото; первая быстрая кнопка — последняя операция.
- **Excel**: Финансы → Статистика → Excel — операции, категории, итоги за период.
- **Сводки**: Настройки → утро 08:00 (баланс, траты, план калорий, ближайшие
  платежи) и вечер 21:00 (напоминание, если день не записан, иначе итог дня) —
  включаются по отдельности.
- **Аналитика**: 7/30/90 дней, графики калорий и категорий, авто-отчёт раз в
  неделю (вс 20:00) или раз в месяц.
